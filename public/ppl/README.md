# PPL × padellabs — concept pitch

Concept deck prepared for Pro Padel League. Five product surfaces organised
by persona — one screen for every human in the league. Built to match PPL's
"padel must be built differently" philosophy.

## Surfaces (by persona)

| # | Persona | File | Device |
|---|---|---|---|
| 01 | Player | `player-hub.html` | Mobile |
| 02 | Referee | `scorer.html` | Tablet |
| 03 | Operator (glance) | `operator-simple.html` | Desktop |
| 04 | Operator (detail) | `operator.html` | Desktop |
| 05 | Analyst / Coach | `analytics.html` | Desktop |

## Scoring language

PPL uses **Golden Point** at 40-40 (sudden-death, next point decides the game).
Do NOT use "Star Point" or "FIP rule" anywhere in PPL-branded surfaces —
those are FIP / Premier Padel terminology, not PPL's.

## Design tokens (for future extensions)
