# PPL × padellabs — concept pitch

Concept deck prepared for Pro Padel League. Three surfaces of what a
player-first PPL platform could look like, built to match their
"padel must be built differently" philosophy.

## Files

| File | What it is |
|---|---|
| `index.html` | The pitch page — scrollable deck with intro, all three mockups via iframe, and partnership proposal |
| `player-hub.html` | Mobile player app concept (iframed from the pitch page) |
| `operator-simple.html` | Simplified league command dashboard concept |
| `operator.html` | Full operations deep view with timing tower |
| `ppl-logo.webp` | Official PPL wordmark, used across all surfaces |
| `screenshots/` | Pre-rendered PNGs for LinkedIn / email / decks |

## URLs after deploy

- Full pitch page: `padellabs.tech/pitch/ppl/`
- Player hub standalone: `padellabs.tech/pitch/ppl/player-hub.html`
- League command: `padellabs.tech/pitch/ppl/operator-simple.html`
- Operations detail: `padellabs.tech/pitch/ppl/operator.html`
